# joeltomaspimentel_devin_demo

Evaluation of whether a fintech engineering team can replace Microsoft Power
Apps with internal tools they own and build with Devin.

- [`internal-tools/`](internal-tools/) — the working prototype: a shared
  platform layer (auth, roles, audit, integrations, spec-driven UI) plus the
  business apps built on it. Start with its README.
- [`internal-tools/devin/`](internal-tools/devin/) — the briefs given to each
  Devin session and `sessions.md`, the log of what each one cost.
